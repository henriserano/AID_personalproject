# Prédiction de performance sportives sur le foot

Avec le début de la coupe du monde, l'objectif est de pouvoir prédire au mieux les différents résultats de la coupe du monde, et pour cela, il faut pouvoir déterminer QUI va gagner la coupe du monde de foot et chaque match.

Agent IA avec des tools sur CrewAI ou autre framework qui utilise LlamaIndex en local (ou LM Studio en fonction) pour faire tout ça en local.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python Model/routes.py
```
